## 🔧 평가 도구별 사용 시나리오

### 🥇 행별 쌍 평가 (`row_pair_evaluator.py`)
**언제 사용**: PA 시스템의 실제 성능을 측정하고 싶을 때 (권장)
```python
# 자동 실행
python row_pair_evaluator.py

# 또는 코드에서
from row_pair_evaluator import RowPairAccuracyEvaluator
evaluator = RowPairAccuracyEvaluator()
results = evaluator.evaluate_accuracy("정답.xlsx", "예측.xlsx")
```

**장점**:
- ✅ 세그먼트 식별자 오류 문제 회피
- ✅ 동적 정렬로 행 수 차이 자동 처리
- ✅ 가장 현실적인 성능 지표
- ✅ 99.5% 정렬 성공률

### 🥈 원문 정확도 평가 (`source_accuracy_evaluator.py`)
**언제 사용**: 데이터 구조 문제를 진단하고 싶을 때
```python
python source_accuracy_evaluator.py
```

**용도**:
- 원문 불일치 패턴 분석
- PA 시스템의 구조적 문제 파악
- 데이터 품질 검증

### 🥉 기본 정확도 평가 (`accuracy_evaluator.py`)  
**언제 사용**: 세그먼트 단위 상세 분석이 필요할 때 (데이터 완벽 시에만)
```python
python accuracy_evaluator.py 정답.xlsx 예측.xlsx
```

**주의사항**:
- ⚠️ PA 시스템의 식별자 오류로 인해 현재는 제한적 유용성
- ⚠️ 97% 번역문 불일치로 인한 왜곡된 결과

## 🔍 문제 해결 FAQ

### Q: 평가 도구가 다른 결과를 보여줍니다
**A**: 평가 방법론이 다르기 때문입니다.
- `row_pair_evaluator.py`: 행별 직접 비교 (권장)
- `accuracy_evaluator.py`: 세그먼트 식별자 기반 (현재 문제 있음)

### Q: 텍스트 유사도가 낮게 나옵니다
**A**: 31%는 PA 시스템으로는 실용적 수준입니다.
- 완전 자동화된 시스템 기준으로 양호한 성능
- 수동 후처리로 추가 개선 가능

### Q: 정렬 성공률은 높은데 텍스트 유사도가 낮습니다
**A**: 정상적인 현상입니다.
- 정렬 성공률: 매칭 가능성 (구조적 안정성)
- 텍스트 유사도: 실제 내용 일치도 (품질)
