## 5. 통계 검증 재현

### 5.1 Level 1: 유사이단 (`로다`)

```python
from scipy.stats import chi2_contingency

# 관측값 (Target: 로다, Control: 무작위)
observed = [[344, 608], [140, 812]]
chi2, p, dof, expected = chi2_contingency(observed)
print(f"χ² = {chi2:.2f}, p = {p:.2e}")
# 예상 출력: χ² = 114.16, p = 1.20e-26
```

### 5.2 Level 2: 쾌절 vs 미절 (`니라` vs `라`)

```python
observed = [[2815, 1417], [2160, 2073]]
chi2, p, dof, expected = chi2_contingency(observed)
print(f"χ² = {chi2:.2f}, p = {p:.2e}")
# 예상 출력: χ² = 208.90, p = 2.38e-47
```

## 6. 트러블슈팅

### Q: `FileNotFoundError: phrase_normalized_anonymized.csv`
A: 데이터셋 경로가 `data/` 폴더 기준인지 확인하세요.

### Q: OpenAI API 오류
A: API 키 설정과 잔액을 확인하세요. GPT-5-nano 모델 사용 권장.

### Q: 인코딩 오류 (mojibake)
A: 모든 파일이 UTF-8로 저장되었는지 확인하세요.
