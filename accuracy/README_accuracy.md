# 관자 정확도 평가 도구 모음

PA 시스템의 성능을 다양한 방법으로 평가하는 포괄적인 도구 모음입니다.

## 📋 평가 도구 종류

### 1. 기본 정확도 평가 (`accuracy_evaluator.py`)
- 구병렬 선생님의 정답 데이터와 PA 출력 비교
- 세그먼트 단위 정확도 평가
- 완전/부분 일치율 분석

### 2. 원문 정확도 평가 (`source_accuracy_evaluator.py`)
- 원문 텍스트 중심 평가
- 문장 식별자 기반 매칭
- 원문 불일치 상세 분석

### 3. 행별 쌍 평가 (`row_pair_evaluator.py`) ⭐ **최신**
- 행별 원문-번역문 쌍 직접 비교
- 동적 정렬 알고리즘 적용
- 실제적인 PA 성능 측정

## 📊 평가 지표

### 행별 쌍 평가 지표 (row_pair_evaluator.py)
1. **정렬 성공률**: 매칭 가능한 행의 비율
2. **텍스트 유사도**: 결합된 "원문|번역문" 텍스트의 유사도
3. **최종 유사도**: 정렬 성공률과 텍스트 유사도의 가중평균
4. **행 수 비교**: 정답 vs 예측 행 수 차이 분석

### 기본 평가 지표 (accuracy_evaluator.py)
1. **완전 일치율 (Exact Match)**
   - 정답과 예측이 세그먼트 순서와 내용이 모두 일치하는 비율
   - 가장 엄격한 평가 기준

2. **텍스트 일치율 (Text Match)**
   - 분할 결과를 합쳤을 때 전체 텍스트가 일치하는 비율
   - 분할은 틀렸지만 내용 손실이 없는지 확인

3. **세그먼트 수 일치율 (Segment Count Match)**
   - 정답과 예측의 세그먼트 개수가 일치하는 비율

4. **부분 일치율 (Partial Match - Jaccard)**
   - 정답과 예측 세그먼트 집합의 교집합/합집합 비율
   - 0~1 사이 값, 1에 가까울수록 유사

5. **F1 점수**
   - 정밀도와 재현율의 조화평균
   - 분할 품질의 종합적 평가

6. **정밀도 (Precision)**
   - 예측한 세그먼트 중 정답에 있는 비율

7. **재현율 (Recall)**
   - 정답 세그먼트 중 예측에서 찾은 비율

## 📁 출력 파일 구조

### 행별 쌍 평가 출력
- `Summary`: 전체 평가 요약
- `Row_Details`: 행별 상세 결과
  - `ground_truth_text`: 정답 결합 텍스트
  - `prediction_text`: 예측 결합 텍스트
  - `text_similarity`: 텍스트 유사도 점수
  - `is_aligned`: 정렬 성공 여부

### 기본 평가 출력
- `문장별_상세결과`: 각 문장의 세부 평가 결과
- `전체_요약`: 전체 평균 지표들
- `Source_Mismatches`: 원문 불일치 문장 목록
- `Execution_Log`: 실행 과정 로그

## 🔧 문제 해결

### 데이터 구조 문제
**문제**: PA 시스템에서 세그먼트 식별자 오류
- **증상**: 97% 번역문 불일치, 데이터 정렬 실패
- **해결**: 행별 쌍 평가 도구 사용 (`row_pair_evaluator.py`)

### 행 수 불일치 문제
**문제**: 정답과 예측의 행 수 차이
- **해결**: 동적 정렬 알고리즘 자동 적용
- **결과**: 99.5% 정렬 성공률 달성

### 컬럼명 인식 오류
**문제**: 다양한 컬럼명으로 인한 인식 실패
- **해결**: 자동 컬럼명 매핑 기능
- **설정**: 코드 내 `detect_columns()` 함수

## 🏗️ 개발자 정보

### 프로젝트 개요
이 도구 모음은 관자 프로젝트의 PA(Paragraph Alignment) 시스템 성능을 종합적으로 평가하기 위해 개발되었습니다.

### 개발 히스토리
1. **accuracy_evaluator.py**: 초기 세그먼트 단위 평가 도구
2. **source_accuracy_evaluator.py**: 원문 중심 평가 및 데이터 구조 문제 발견
3. **row_pair_evaluator.py**: 행별 직접 비교를 통한 실제적 성능 측정

### 주요 발견사항
- **PA 시스템 한계**: 세그먼트 식별자 할당 오류로 인한 데이터 정렬 문제
- **평가 방법론**: 행별 쌍 비교가 가장 현실적인 성능 지표 제공
- **실제 성능**: 관자3 데이터 기준 38.3% 최종 유사도 (실용적 수준)

### 기술 스택
- **언어**: Python 3.8+
- **주요 라이브러리**: pandas, openpyxl, difflib
- **평가 알고리즘**: 동적 정렬, 텍스트 유사도, Jaccard 계수
