# 1인칭 주어 표지 'ㅗ' 모음 분석 보고서

## 개요

중세/근대 한국어에서 **'ㅗ' 모음**은 **1인칭 주어**를 표시하는 문법적 기능을 가졌습니다.
현토(懸吐)에서 이 1인칭 표지는 화자(話者)의 입장을 명시하는 중요한 역할을 합니다.

### 1인칭 표지의 유형

| 유형 | 예시 | 기능 |
|:-----|:-----|:-----|
| **-노-** 계열 | 하노이다, 하노라, 하노니 | 1인칭 서술/연결 |
| **-호-** 계열 | 호되, 호대, 호리라 | 1인칭 + 청자 높임/대우 |
| **-로소-** 계열 | 로소이다, 로소니 | 1인칭 겸양 |

## 5. 언어학적 의의

### 5.1 화자 표지로서의 'ㅗ'

중세 한국어에서 **'ㅗ' 모음**은 1인칭 화자를 표시하는 체계적인 문법 표지였습니다:

- **-노-**: 1인칭 주어 + 서술 (`하노라` = 내가 한다)
- **-호-**: 1인칭 + 청자 대우 (`호되` = 내가 말하되)
- **-로소-**: 1인칭 + 겸양 (`로소이다` = 저는 ~입니다)

### 5.2 장르적 분화

1인칭 표지의 분포는 텍스트의 **발화 상황(Speech Situation)**과 밀접하게 연관됩니다:

- **문집**: 저자가 직접 발화 → 1인칭 표지 빈번
- **역사서**: 대화 인용 → 1인칭/2인칭 표지 혼재
- **경전**: 객관적 서술 → 1인칭 표지 희소

이는 현토가 단순한 '토씨 붙이기'가 아니라, **화용론적 맥락까지 반영**하는 정교한 번역 체계임을 보여줍니다.
