# XLSX Scripts

XML 파일 쌍을 Excel 형식으로 변환하는 스크립트 모음입니다.

## 🎯 핵심 개념

### 일반 서종 vs 특수 서종

43권의 책은 **문단 단위 구조**에 따라 두 가지로 나뉩니다.

**공통점:**
- `<w>`, `<c>`, `<s>` 태그 구조는 동일
- 문장 ID(`<s>` 태그의 `id` 속성) 체계 동일

**차이점:**
```
일반 서종 (39권):
  <원문 식별자="ID:W1">  ← 문단식별자
    <s id="s001">...</s>
    <s id="s002">...</s>
  </원문>

특수 서종 (4권):
  <단락 id="1">  ← 문단식별자
    <s id="s001">...</s>
    <s id="s002">...</s>
  </단락>
```

**처리 전략:**
1. **일반 서종 먼저 실행** → 39권 처리
2. **특수 서종 나중에 실행** → 4권 처리 (덮어쓰기 방지)

**특수 서종 목록 (4권):**
- 예기집설대전1
- 당시삼백수1, 2, 3

### 🚀 실행 명령어 (순서대로)

#### 0️⃣ 서종 감별 (선택사항)

```bash
docker-compose run --rm csp python xlsx_scripts/find_danlak_books.py
```
- **목적**: 원문 식별자가 모두 동일한 책 탐지
- **출력**: 단락 ID 기반 처리가 필요한 책 목록

---

#### 1️⃣ 구병렬 생성 (전체 43권)

```bash
docker-compose run --rm csp python xlsx_scripts/xml_to_tsv_converter.py
```
- **대상**: 전체 43권
- **출력**: `{책이름}_구병렬.xlsx`
- **컬럼**: 문장식별자, 구식별자, 원문, 번역문
- **예상 행 수**: 318,086개

---

#### 2️⃣ 문장병렬 생성

**2A. 일반 서종 (39권)**
```bash
docker-compose run --rm csp python xlsx_scripts/xml_to_sentence_parallel.py
```
- **대상**: 춘추좌씨전, 자치통감강목, 당송팔대가문초
- **출력**: `{책이름}_문장병렬.xlsx`
- **컬럼**: 문단식별자, 문장식별자, 원문, 번역문

**2B. 특수 서종 (4권)**
```bash
docker-compose run --rm csp python xlsx_scripts/extract_yeogi.py
```
- **대상**: 예기집설대전1, 당시삼백수1~3
- **출력**: `{책이름}_문장병렬.xlsx`
- **특징**: 단락 태그 기반 추출, s_id 또는 순서 매칭

---

#### 3️⃣ 문단식별자 정규화 (전체 43권)

```bash
docker-compose run --rm csp python xlsx_scripts/renumber_excel_indices.py
```
- **대상**: 모든 `*_문장병렬.xlsx` 파일
- **기능**: `ID:W1`, `ID:W10` → `1`, `2`, `3`... 누적 번호
- **예시**:
  ```
  ID:W10 → 1번 문단
  ID:W10 → 1번 문단
  ID:W1  → 2번 문단  (식별자 변화)
  ID:W1  → 2번 문단
  ```

---

#### 4️⃣ 데이터 품질 검증 (선택사항)

```bash
docker-compose run --rm csp python xlsx_scripts/log_nan_values.py
```
- **대상**: 모든 `*_문장병렬.xlsx` 파일
- **출력**: `/workspace/nan_log.txt`
- **내용**: NaN 값 위치 및 전후 3행 맥락
- **특징**: NaN 값 자체는 보존 (수정하지 않음)

---

#### 5️⃣ 문단병렬 생성

**5A. 일반 서종 (39권)**
```bash
docker-compose run --rm csp python xlsx_scripts/create_paragraph_parallel.py
```
- **입력**: 일반 서종의 `*_문장병렬.xlsx`
- **출력**: `{책이름}_문단병렬.xlsx`
- **컬럼**: 문단식별자, 원문, 번역문
- **작동**: 같은 문단식별자끼리 공백으로 연결

**5B. 특수 서종 (5권)**
```bash
docker-compose run --rm csp python xlsx_scripts/create_yeogi_paragraph.py
```
- **대상**: 예기집설대전1, 2 + 당시삼백수1~3
- **출력**: `{책이름}_문단병렬.xlsx`
- **특징**: 단락 ID 기반 병합

---

#### 6️⃣ 구병렬에 문단식별자 추가 (전체 43권)

│   └── 당송팔대가문초구양수1_문단병렬.xlsx
├── 당송팔대가문초구양수2/
