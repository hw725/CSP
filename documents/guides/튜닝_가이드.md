# SA 정렬 가중치 튜닝 가이드 (Boundary & Similarity)

이 문서는 SA(문장/구 정렬)의 핵심 가중치 두 축, 경계 정합(boundary)과 유사도 선명도(similarity sharpening)를 중심으로 실무 튜닝 방법을 정리합니다. 나머지 파라미터는 기본값 유지 후 필요 시 미세 조정하세요.

## 핵심 옵션 요약

- --boundary-bonus (기본 0.3)
  - 문장 경계에서 정렬이 끝나면 보너스를 부여합니다.
  - 경계가 자주 어긋나면 값을 올려 경계 준수를 강화합니다.

- --particle-bonus (기본 0.2)
  - 한국어 토씨(을/를/이/가/은/는/에/에서/으로/와/과 등) 경계에서 보너스를 부여합니다.
  - 조사 기준의 구 경계를 더 잘 따르게 합니다.

- --dp-window (기본 2)
  - 기대 위치 주변에서만 후보를 적극적으로 탐색하여 순서를 안정화합니다.
  - 2~3 범위를 권장합니다. 너무 크면 뒤섞임이 늘 수 있습니다.

- --sim-gamma (기본 1.5)
  - 유사도 점수를 지수로 샤프닝합니다. 1.0은 변화 없음.
  - 애매한 매칭을 더 선명하게 하고자 할 때 올립니다(1.4~1.6 권장).

## 빠른 처방

- 경계가 자주 어긋남
  - boundary-bonus ↑, particle-bonus ↑
  - dp-window는 2~3 유지

- 매칭이 애매함(비슷비슷한 후보가 섞임)
  - sim-gamma ↑ (1.4~1.6)
  - 샤프닝이 너무 강해 딱딱해지면 약간 낮추세요(예: 1.35~1.45)

## 권장 시작값

- --boundary-bonus 0.30
- --particle-bonus 0.20
- --dp-window 2
- --sim-gamma 1.50

## 단계별 튜닝 절차

1) 경계 안정화부터
   - boundary-bonus 0.30 → 0.35 (효과 없으면 0.40까지)
   - particle-bonus 0.20 → 0.25 (효과 없으면 0.30까지)
   - dp-window는 2 유지, 필요 시 3까지

2) 유사도 선명화
   - sim-gamma 1.50 → 1.55 (효과 없으면 1.60까지)
   - 너무 경직되면 1.45로 낮춤

3) 교차 점검
   - 경계 강화로 매칭이 과도하게 제한되면 sim-gamma를 먼저 조절해 분별력을 확보
   - sim-gamma를 높였는데도 뒤섞임이 남으면 boundary/particle을 추가 상승

## 부작용과 대처

- boundary/particle을 과도하게 높임
  - 드물게 의미상 긴 구가 잘리는 경향 → 두 보너스를 0.05~0.1 낮춤

- sim-gamma를 과도하게 높임
  - 약한 연관 구가 배제되어 빈 구가 생기거나 과도한 1:1 강제 → 0.05~0.1 낮춤

## 실행 예시 (Windows cmd)

```bat
REM 경계 강화
python sa\main.py input.xlsx output.xlsx --boundary-bonus 0.35 --particle-bonus 0.25 --dp-window 2

REM 애매한 매칭 선명화
python sa\main.py input.xlsx output.xlsx --sim-gamma 1.55

REM 함께 적용
python sa\main.py input.xlsx output.xlsx --boundary-bonus 0.35 --particle-bonus 0.25 --dp-window 2 --sim-gamma 1.5
```

## 참고: 관련 파라미터 상호작용

- distance-decay (기본 0.9)
  - 기대 위치에서 벗어날수록 점수 감쇠. dp-window와 함께 순서 안정화에 기여.

- length-penalty (기본 0.05)
  - 비정상적으로 긴/짧은 구를 억제. 경계 강화 시 과분할/과소분할의 미세 조정에 사용.

## 체크리스트(요약)

- 경계 문제 → boundary/particle 우선
- 순서 뒤섞임 → dp-window 2~3 유지, distance-decay 기본 유지
- 애매한 유사도 → sim-gamma 1.4~1.6

필요 이상으로 많은 옵션을 건드리지 말고, 위 4가지만으로 먼저 수렴시키는 것을 권장합니다.
# SA 정렬 가중치 상세 가이드 (Boundary & Similarity)

본 문서는 SA(Sentence Aligner)의 동적 프로그래밍(DP) 스코어링 가중치 중 현업에서 가장 영향도가 큰 두 축을 집중 설명합니다.
- 경계 정렬 강화: boundary-bonus, particle-bonus, dp-window
- 유사도 선명화: sim-gamma

현재 기본값(권장값):
- boundary-bonus: 0.30
- particle-bonus: 0.20
- dp-window: 2
- sim-gamma: 1.5

추가 관련 파라미터(참고):
- distance-decay: 0.9 (예상 위치에서 벗어날수록 감쇠)
- length-penalty: 0.05 (분할 길이 과도/과소 페널티)

---

## 1) 경계가 자주 어긋난다

증상:
- 한국어 번역의 문장/구 경계가 원문 의미 경계와 자주 엇나감
- 토씨(은/는/이/가/을/를/에/에서/으로/와/과/도/만/뿐/까지 등) 직후에서 어긋나는 경향

권장 조치:
- boundary-bonus ↑ (예: 0.25 → 0.30)
- particle-bonus ↑ (예: 0.25 → 0.30)
- dp-window는 2~3 범위 유지 (너무 키우면 순서 제약 약화)

효과:
- 구 경계와 조사 경계에 힌트를 더 크게 반영하여 경계 일치 비율 상승
- 과도하게 키우면 의미 유사도보다 경계 힌트가 과대 반영될 수 있으므로 0.05~0.1 단위로 점진 조정 권장

체크리스트:
- 빈 구절(empty segment) 비율 감소 여부
- 문장 끝(문장부호·어절 경계)에서의 정렬 안정성 개선 여부

예시:
```bash
python sa\main.py input.xlsx output.xlsx --boundary-bonus 0.30 --particle-bonus 0.30 --dp-window 2
```

---

## 2) 매칭이 애매함(유사도 대비가 낮다)

증상:
- 후보 간 코사인 유사도가 전반적으로 비슷해 최적 경로가 들쑥날쑥
- 경계는 맞지만 어느 후보가 더 맞는지 구분이 흐림

권장 조치:
- sim-gamma ↑ (1.4 ~ 1.5 권장)
  - 값이 커질수록 높은 유사도는 더 높게, 낮은 유사도는 더 낮게(샤프닝)
  - 너무 크게 올리면 작은 노이즈에도 경직될 수 있음 → 0.05 단위로 미세 조정

효과:
- 애매한 케이스에서 상위 후보/하위 후보의 점수 격차 확대 → 경로 안정화

예시:
```bash
python sa\main.py input.xlsx output.xlsx --sim-gamma 1.5
```

---

## 3) 두 가지를 함께 조정하는 경우

권장 시작점:
```bash
python sa\main.py input.xlsx output.xlsx \
  --boundary-bonus 0.30 \
  --particle-bonus 0.30 \
  --dp-window 2 \
  --sim-gamma 1.45
```

실무 팁:
- dp-window는 2를 기본으로, 순서 유연성이 필요할 때만 3으로 상향하세요.
- boundary/particle 보너스는 합계가 0.5~0.7를 넘지 않게 시작하세요.
- sim-gamma는 1.4에서 1.5 사이 탐색을 권장합니다.

## 5) 문제 해결 가이드(FAQ)

Q1. 경계는 좋아졌는데 의미가 약간 무시되는 느낌입니다.
- A. boundary-bonus / particle-bonus를 각각 0.05 낮추거나 sim-gamma를 0.05 올려 의미 구분력을 보완하세요.

Q2. dp-window를 4 이상으로 키우면 좋아질까요?
- A. 일반적으로 비권장입니다. 순서 제약이 약해져 잡음에 민감해질 수 있습니다. 2~3 범위 권장.

Q3. 값이 충돌하는 느낌입니다. 어디부터 손대야 하나요?
- A. 우선 sim-gamma로 유사도 대비를 확보한 후, boundary/particle을 0.05 단위로 보정하세요.

# PA 정렬 가중치 튜닝 가이드 (문단→문장 분할)

PA는 원문을 어절 경계에서만 분할하고, 번역문 문장과 의미 임베딩으로 맞추는 하이브리드 방식입니다. 기본값은 안정성과 재현성을 우선한 권장치입니다.

## 기본값(권장값)

- 임베더: BGE-M3 (기본) — `--embedder bge`
- 배치/워커: `--max-workers 4`, `--batch-size 50` (OpenAI 사용 시)
- 유사도 버킷/가중치:
  - 상위: `--sim-thr-high 0.15`, `--sim-mul-high 5.0`, `--sim-add-high 0.5`
  - 중상: `--sim-thr-mid 0.10`, `--sim-mul-mid 4.0`, `--sim-add-mid 0.3`
  - 중간: `--sim-thr-low 0.05`, `--sim-mul-low 3.0`, `--sim-add-low 0.2`
  - 하위: `--sim-thr-verylow 0.01`, `--sim-mul-verylow 2.0`, `--sim-add-verylow 0.1`
  - 완화: `--sim-thr-min -0.05`, `--sim-add-min 0.05`
  - 페널티: `--sim-penalty-mul 0.2`
- 구조 보너스/확실성/품질:
  - `--struct-degu-bonus 0.5`, `--struct-hard-degu-bonus 0.4`
  - `--struct-ni-bonus 0.2`, `--struct-iyo-bonus 0.15`, `--struct-ra-da-bonus 0.1`
  - `--struct-cert-thr 0.4`, `--struct-cert-mul 2.0`
  - `--quality-thr 0.8`, `--quality-mul 1.5`
- 토씨 보너스: `--particle-bonus 0.0` (기본 비활성; 어순 차이 영향을 줄이기 위함)

이 값들은 `pa/sentence_splitter.py`의 WEIGHTS 기본과 일치합니다.

## 빠른 처방

- 원문 분할이 번역문 길이 비율과 다소 어긋남 → 길이 기반 후보도 이미 고려되므로, 유사도 대비 강화로 해결하는 편이 안전합니다: `--sim-mul-mid`/`--sim-mul-low` 약간↑, `--sim-penalty-mul` 약간↑.
- 특정 고전 어미(…이요/…니) 패턴이 잘 이어질 때 점수를 더 주고 싶음 → `--struct-hard-degu-bonus` 0.4 → 0.45~0.5.
- 과하게 경직됨(긴 구가 부자연스레 잘림) → `--sim-penalty-mul` 소폭↓, 또는 `--quality-thr` 0.8 → 0.85로 상향해 고품질 과보정 완화.

## 실행 예시 (Windows cmd)

```bat
REM 기본 실행 (BGE)
python pa\main.py input.xlsx output.xlsx

REM OpenAI 사용 (워커/배치 조정)
python pa\main.py input.xlsx output.xlsx --embedder openai --max-workers 4 --batch-size 100

REM 유사도 대비 강화 (중간/하위 구간)
python pa\main.py input.xlsx output.xlsx --sim-mul-mid 4.5 --sim-mul-low 3.5 --sim-penalty-mul 0.25

REM 구조 패턴 보너스 강화 (이요…니)
python pa\main.py input.xlsx output.xlsx --struct-hard-degu-bonus 0.5
```

## 체크리스트

- 빈 세그먼트가 생기면: `--sim-penalty-mul`↓ 또는 `--quality-thr`↑
- 번역 길이 비율과 동떨어진 분할이 잦으면: `--sim-mul-low|mid` 미세↑로 길이 후보의 보정 여지를 확대
- 토씨 보너스로 어순 왜곡이 의심되면: `--particle-bonus 0.0` 유지 권장
