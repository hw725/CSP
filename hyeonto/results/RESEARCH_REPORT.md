### PHASE 5: 장르별 통계 분석

#### Level 3: 기사지단 가설 검증

**가설**: "하다" 마커는 역사서에서 특히 높은 빈도로 나타난다.

##### 장르별 분포

```
역사서     : 253,118건 중  19,841건 ( 7.84%)
문집      : 197,060건 중   3,143건 ( 1.59%)
경전      :  21,530건 중      17건 ( 0.08%)
시       :  14,181건 중       0건 ( 0.00%)
기타      : 157,468건 중      41건 ( 0.03%)
```

##### 통계 검정 결과

- **χ² = 21,898.05**
- **p-value = 0.00** (매우 유의미)
- **결론**: ✅ **가설 기각** - 역사서에서 "하다"가 통계적으로 유의미하게 높음
  - 역사서: 7.84% vs 비역사서: 1.16%
  - **상대 위험도**: 6.76배 높음
